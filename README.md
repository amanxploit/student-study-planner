# Student Study Planner

A beginner-friendly web application designed to help students organize their study tasks and subjects.

## Project Goals
- Practise HTML and CSS
- Learn JavaScript through practical features
- Build a useful tool for student life
- Learn Git and GitHub

## Planned Features
- Subject-wise task organization
- Add and complete study tasks
- Track study progress
- Save tasks in the browser

## Technologies
- HTML
- CSS
- JavaScript (as features are implemented)

## Project Status
In development.
